HELP & SUPPORT

Need help?

A few quick answers to common attendance questions.

My code will not scan
Check the brightness of the screen, clean your camera lens and make sure the session has not expired.
I do not have data or a working phone
Tell the lecturer before leaving. The proposed system includes a manual verification fallback.
My attendance is missing
Show the lecturer your course and class time. A lecturer or administrator can review the session record.
The real system should provide a help contact and a clear process for correcting attendance errors.
