SMART ATTENDANCE SYSTEM - INTERACTIVE CONCEPT PROTOTYPE

HOW TO OPEN
1. Extract the full ZIP file first. Keep all folders together.
2. Open the folder 02_Interactive_Prototype.
3. Double-click index.html, or double-click Run_Prototype.bat on Windows.
4. Use the Student dashboard, Scan, History and Help navigation.
5. Click the Lecturer View button to open the lecturer concept screen. Use Student View to return.

HOW TO DEMONSTRATE IT
- From the student dashboard, select Scan QR to mark attendance.
- Select Simulate QR scan.
- Review the Attendance recorded confirmation.
- Open Attendance History to see the demo record.
- From Lecturer View, review the sample session QR and example attendance list.

IMPORTANT LIMITATIONS
This is a front-end HCI concept prototype. The scan action is simulated; it does not activate the camera. The QR image contains demo text only. There is no live university login, backend, database, network service, security validation or official attendance record. Sample course names, times, students and counts are illustrative. Do not use this prototype to record real attendance.

The prototype uses the image ../03_Visual_Assets/Demo_Session_QR.png. Do not move index.html away from its folder or move the Visual Assets folder.
